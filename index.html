About.

Twitch Chat-to-Voice System — feat. Jerry

Reads Twitch chat messages aloud in real time through a multi-engine TTS pipeline. Each viewer can be assigned their own voice — from Google Cloud and ElevenLabs AI voices to the retro SAM synthesiser and Animalese (Animal Crossing-style phoneme sounds). Built on async queues so TTS, sound effects, and keyboard controls all run concurrently without blocking each other.

  • Animalese mode: custom letter-sample phoneme synthesis

  • Animated mouth overlay that syncs to speech output

VOD YouTube Uploader

Active

Batch Upload Tool for Streamers

Built to replace the unreliable YouTube web UI for uploading large stream recordings. Handles batch queues, auto-resumes failed uploads, and runs an ffmpeg loudnorm pass on each file before upload to fix the inconsistent audio levels common in Twitch VODs. Distributed as a standalone .exe so non-technical streamers can use it without touching a terminal.

  • ffmpeg loudnorm audio normalisation baked into the upload pipeline
  • Batch folder upload with automatic resume on failure
  • OAuth Google sign-in — no API keys to manage manually
  • Supports files 20 GB+, ships as a PyInstaller .exe
